I got inspired by Epic's beautiful Ninety Days projects, so I challenged myself to create an environment in three days. Everything was built inside Unreal Engine using Quixel Megascans, with some assets from the marketplace, and the human created using MetaHuman Creator.

I really enjoyed working on this project and will surely do another challenge in the future.
